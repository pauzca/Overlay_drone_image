about=This plugin wraps the closeup-ortho processing pipeline for Phase One cameras. Given a reference orthomosaic, a DSM, and a folder of geotagged Phase One images, it (1) finds the most-nadir image covering a user-selected target point, (2) orthorectifies it, (3) aligns it to the orthomosaic via SIFT feature matching, and (4) loads the result as a read-only virtual raster layer inside QGIS.
